DevSecOps Learning Path

خريطة طريق كاملة مبنية على خبرتك في الـ Software Testing. كل توبيك فيه: لوجو الأدوات، هدف الدخول، مهارات الخروج (بتتحفظ تلقائياً)، مصادر عربي وإنجليزي، مشروع عملي بخانة لرابط الريبو، وملاحظاتك الخاصة.

مبنية على: 10–15 ساعة/أسبوع ≈ 9 شهور (الواقعي ~12 شهر مع الكلية والشغل) • أسلوب: Bootcamp أولاً ثم تعميق • القاعدة: العربي للفهم الأول، والإنجليزي هو الأساس.

قبل ما تقدّم على أول وظيفة SDET / DevOps، دول لازم يكونوا جاهزين:

قواعد الطريق (ارجعلها كل شهر)

  • مشاريع مش شهادات. الـ recruiter بيفتح GitHub قبل قائمة الكورسات. كل مرحلة لازم تخرج منها بـ repo موثق.
  • فيديو ساعة = ساعة تطبيق. لو مش بتكتب الـ commands بإيدك، انت بتتفرج مش بتتعلم.
  • خبرة التستنج ميزتك. قوّيها في اتجاه SDET (automation + API + CI) — ده نفسه بداية طريق الـ DevOps.
  • باب الدخول SDET / QA Automation مش "Junior DevOps" مباشرة. التحول بيحصل جوه الشغل بعد سنة-سنتين.
  • أداة واحدة من كل فئة: GitHub Actions قبل Jenkins، AWS بس، Docker بس.
  • وثّق رحلتك على LinkedIn بوست إنجليزي قصير بعد كل مشروع.
  • الشهادات اللي تستاهل فلوس: AWS SAA ثم CKA. الباقي المجاني بيكفي.
